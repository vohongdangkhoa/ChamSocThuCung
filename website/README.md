# Tài nguyên giao diện

Thư mục này chứa CSS và JavaScript mà Razor Pages sử dụng:

- `css/giao-dien.css`: màu sắc, bố cục và biểu mẫu.
- `js/khach-hang.js`: thao tác của khách hàng.
- `js/van-hanh.js`: thao tác của nhân viên, bác sĩ, quản trị.
- `js/tai-khoan.js`, `js/xac-thuc.js`, `js/dang-nhap.js`: tài khoản và đăng nhập.
- `js/api.js`, `js/cau-hinh.js`, `js/chung.js`: gọi API, cấu hình và hàm chung.

Giao diện đang chạy nằm trong `../backend/PetNoVaApi/Pages/`, mỗi màn hình là một file `.cshtml`. Các file HTML tĩnh cũ còn trong lịch sử Git để đối chiếu. Xem README ở thư mục gốc để biết cách chạy và tìm file.
